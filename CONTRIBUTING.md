# Contributing

Analytics Lab welcomes technical discussion, bug reports, benchmarks, test cases, and code contributions that advance next-generation video analytics.

## Donor-code rules

Do not submit copied or adapted third-party code unless:
1. the upstream source is identified;
2. the exact license is identified;
3. redistribution and modification are permitted;
4. required notices are included; and
5. THIRD_PARTY.md is updated.

Do not submit code, datasets, model weights, or other material governed by terms that conflict with the project's intended commercial licensing without prior approval.

## Engineering expectations

New analytics should include:
- a clear problem statement;
- defined inputs and outputs;
- confidence and failure behavior;
- test or benchmark coverage;
- provenance for external dependencies;
- a path to standardized Analytics Lab event output;
- documentation of known limitations and false-positive risks.

Security, safety, life-safety, and evidentiary claims must be supported by testing rather than marketing language.
